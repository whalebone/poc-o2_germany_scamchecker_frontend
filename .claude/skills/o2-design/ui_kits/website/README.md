# o2 Website UI Kit

Pixel-credible recreation of an o2.de–style marketing page using the brand foundations in this design system. Built as JSX modules that compose into a single landing page.

## Components

| File | Purpose |
|---|---|
| `Header.jsx` | Beyond Blue top bar — logo, main nav, utility icons (Shop, Suche, Mein O₂, Warenkorb). |
| `Hero.jsx` | Stage hero with Blauverlauf background, Stage-Bubble + floating price card. |
| `Tariffs.jsx` | 3-up tariff cards; middle/last highlighted with Blauverlauf. Reusable `<TariffCard>`. |
| `Features.jsx` | 4-up benefit row (5G Plus, Abdeckung, Roaming, Testsieger) with solid-blue icon tiles. |
| `Sections.jsx` | Testimonial pull-quote + Blauverlauf CTA strip. |
| `Footer.jsx` | Black footer w/ 4 columns + legal row. |

## Caveat

Reconstructed from the brand guidelines and the PowerPoint master template — **no o2.de source code was available**. If you have access to o2's Storybook / repo, please attach so I can align component implementations.
